# Build and install FlatCheck on Android

The repository builds the Android APK automatically with GitHub Actions whenever you push to `main`.

## From your phone

1. Open the FlatCheck repository on GitHub.
2. Open the **Actions** tab.
3. Open **Build FlatCheck APK**.
4. Wait for the latest run to finish with a green check.
5. Open that run and scroll to **Artifacts**.
6. Download **flatcheck-apk**.
7. Open the downloaded ZIP, extract the APK, and install it on your Android phone.

If Android blocks the installation, allow your browser or file manager to install unknown apps, then retry.

## Package

Application ID: `com.flatcheck.app`
Version: `1.0.0+1`
